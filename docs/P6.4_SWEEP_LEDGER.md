## Sweep Items

### 1. Loading States ✓
- **What:** Every async operation shows a loading indicator with a descriptive label.
- **Implementation:** `src/lib/ux/helpers.js` → `LoadingState.create(label, variant)`
- **Features:** Spinner, skeleton, and progress variants. Stale detection (`isStale`) for stuck loaders (30s default).
- **Test:** `scripts/test-ux.js` Tests 9–10 (LoadingState create + isStale)
- **Status:** FIXED ✓

### 2. Empty States ✓
- **What:** Every list/table shows a meaningful empty state with icon, title, description, and optional CTA.
- **Implementation:** `src/lib/ux/helpers.js` → `EmptyState.create(icon, title, description, actionLabel, action)` + `EmptyState.isEmpty(data)`
- **Features:** Universal emptiness check (null, undefined, empty array, empty object, empty string). CTA action support.
- **Test:** `scripts/test-ux.js` Tests 11–12
- **Status:** FIXED ✓

### 3. Confirm Dialogs ✓
- **What:** Destructive actions (delete, clear, pause) require confirmation. Non-blocking, promise-based.
- **Implementation:** `src/lib/ux/helpers.js` → `ConfirmDialog.show(message, opts)` + `ConfirmDialog.confirmAndRun(message, action, opts)`
- **Features:** Browser uses native `window.confirm`. Headless/test uses `defaultValue` param. Returns Promise<boolean>.
- **Test:** `scripts/test-ux.js` Tests 13–14
- **Status:** FIXED ✓

### 4. Optimistic UI ✓
- **What:** UI updates immediately on user action, reverts to previous state if the server call fails.
- **Implementation:** `src/lib/ux/helpers.js` → `optimisticUpdate(applyFn, actionFn, revertFn)`
- **Features:** Apply → async action → revert on error. Returns `{ ok, result, error, reverted }`. Works with or without revert function.
- **Test:** `scripts/test-ux.js` Tests 15–17
- **Status:** FIXED ✓

### 5. Keyboard Shortcuts ✓
- **What:** Global keyboard shortcut registry for power-user navigation.
- **Implementation:** `src/lib/ux/helpers.js` → `registerShortcut(combo, handler, opts)` + `unregisterShortcut(combo)` + `listShortcuts()`
- **Features:** Combo parsing (ctrl+shift+key), preventDefault control, description for help UI, returns unregister function. Browser-only listener.
- **Test:** `scripts/test-ux.js` Tests 18–19
- **Status:** FIXED ✓

### 6. Copy-Paste Safety ✓
- **What:** Pasted text is sanitized to prevent injection and corruption.
- **Implementation:** `src/lib/ux/helpers.js` → `sanitizeClipboard(text, opts)` + `safePaste(eventOrText, opts)` + `parsePastedEmails(text)`
- **Features:** Strips null bytes and control chars (0x00-0x08, 0x0B, 0x0C, 0x0E-0x1F, 0x7F). Normalizes CRLF→LF. Collapses multiple spaces. Optional HTML tag stripping. Max length enforcement. Email parsing with dedup.
- **Test:** `scripts/test-ux.js` Tests 20–23
- **Status:** FIXED ✓

### 7. Timezone-Correct Dates ✓
- **What:** All dates displayed in Asia/Dhaka (Bangladesh, UTC+6) timezone. No server-UTC leakage to UI.
- **Implementation:** `src/lib/ux/helpers.js` → `formatDate(date)`, `formatDateTime(date)`, `formatDateISO(date)`, `formatRelative(date)`
- **Features:** `TIMEZONE = 'Asia/Dhaka'`. Intl.DateTimeFormat with timeZone option. ISO 8601 for API/sorting. Bangla relative time ("এইমাত্র", "X মিনিট আগে", "X ঘন্টা আগে", "X দিন আগে"). Null/invalid date safety.
- **Test:** `scripts/test-ux.js` Tests 4–8
- **Status:** FIXED ✓

### 8. Complete Bangla i18n Strings ✓
- **What:** Every user-facing string exists as a Bangla translation in a single source of truth.
- **Implementation:** `src/lib/i18n/bn.js` → `STRINGS` dictionary + `t(key)` + `tFormat(key, params)`
- **Coverage:** 70+ strings across categories:

  - `campaign.*` (17 strings: title, new, name, subject, sender, send, pause, resume, status.*, progress, sent, failed, total, recipients, sandbox)
  - `validator.*` (8 strings: valid, invalid, duplicates, bounceRisk, blacklisted, highRisk, grade, processing)
  - `error.*` (10 strings: matching sendGuard FAILURE_MODES exactly)
  - `settings.*` (6 strings)
  - `package.*` (8 strings: free/basic/pro/enterprise, quotas)
  - `aiPool.*` (7 strings)
  - `shortcut.*` (5 strings)
  - `toast.*` (6 strings)
- **Test:** `scripts/test-ux.js` Tests 1–3, 24
