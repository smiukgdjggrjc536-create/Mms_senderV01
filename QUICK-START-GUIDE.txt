================================================
SMS CAMPAIGN SYSTEM - QUICK START GUIDE
================================================

YOUR WEBSITES (use any one):
  Vercel:  https://mms-sender-v01.vercel.app
  Netlify: https://mms-sender-v01.netlify.app

================================================
STEP 1: LOGIN (FIRST TIME = ADMIN)
================================================

1. Open Chrome on your phone
2. Go to: https://mms-sender-v01.vercel.app
3. You will see login page
4. Enter:
   - Email: (your email, e.g. admin@test.com)
   - Password: (choose a strong password, e.g. MyAdmin2025!)
5. Press "Login / Register" button
6. FIRST LOGIN = AUTOMATICALLY BECOMES ADMIN
7. Admin Panel will open

>>> IMPORTANT: Remember your email + password!
>>> The first login becomes the admin account.

================================================
STEP 2: ADD API KEYS (IN ADMIN PANEL)
================================================

A) Add Gemini API Key (for AI spam filter):
   - Go to: https://aistudio.google.com/apikey
   - Login with Google
   - Click "Create API Key"
   - Copy the key
   - Paste in "Gemini API Key" box in Admin Panel
   - Press "Save Gemini Key"

B) Add SMS Gateway API Key (for sending SMS):
   - Get API key from your SMS provider
   - Paste in "SMS Gateway API Key" box
   - Press "Save SMS Key"

================================================
STEP 3: ADD MORE MONGODB (IF NEEDED)
================================================

MongoDB free tier = 512MB limit.
When database is full, add another MongoDB account:

1. Go to: https://account.mongodb.com
   (or create new account)
2. Build a Database -> M0 (Free)
3. Connect -> Drivers -> Node.js
4. Copy connection string
   (looks like: mongodb+srv://user:pass@cluster...)
5. In Admin Panel -> MongoDB Connections:
   - Label: "Account 2"
   - URI: (paste connection string)
   - Press "Add Connection"
6. Press "Set Active" to switch database

================================================
STEP 4: SEND SMS CAMPAIGN
================================================

1. In Admin Panel, switch to User Panel
   (or login as regular user)
2. Enter phone numbers (one per line or comma)
3. Write your SMS message
4. Press "Send Campaign"
5. AI spam filter checks the message:
   - Good message = sent
   - Spam message = blocked
6. Campaign history shows below

================================================
QUOTA SYSTEM
================================================

- Each user gets 100 SMS per month
- Admin can change user limits
- When quota is finished, no more SMS

================================================
BOOKMARK ON PHONE
================================================

1. Open site in Chrome
2. Press 3 dots (top right)
3. Press "Add to Home screen"
4. Press "Add"
5. Now you have app icon on phone!

================================================
TROUBLESHOOTING
================================================

Login not working?
  -> Check email + password
  -> Try other link (Vercel vs Netlify)

SMS not sending?
  -> Check SMS Gateway API Key is added
  -> Check quota not finished

AI filter not working?
  -> Check Gemini API Key is added
  -> Free quota resets daily

Database full?
  -> Add new MongoDB connection in Admin Panel
  -> Set it as Active

================================================
SUMMARY
================================================

  Login:        Open link -> email + password
  First login:  = Admin automatically
  Gemini Key:   Admin Panel -> Save Gemini Key
  SMS Key:      Admin Panel -> Save SMS Key
  New MongoDB:  Admin Panel -> Add Connection
  Send SMS:     User Panel -> numbers + message
  Quota:        100 SMS per user
